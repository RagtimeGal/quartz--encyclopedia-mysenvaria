This week the URL for the Encyclopedia has changed! As part of a larger push from myself to work on other projects the URL has changed from `https://mysenvaria.ragno.wiki` to `https://mysenvaria.ragno.studio`! If it's properly set up the prior URL should redirect to the new URL for the next year-or-so until my payment expires.

Besides that this week has also seen a rewrite of the Encyclopedia's [[_index|home page]]. The home page now has a featured page and fun facts section, which will (hopefully, if all is set up right!) automagically update every day! It's inspired/stolen from [Wikipedia's main page](https://en.wikipedia.org/wiki/Main_Page) which includes ongoing news, fun facts, and featured articles (among other things). I'm hoping this will help in making the Encyclopedia easier and more fun to navigate.

This week has also seen a rewrite of the [[Meta/Metadata|Metadata]] page, making it much more pleasant to look at and much easier to understand! Quite proud of myself for that one...
